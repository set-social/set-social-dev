Adding a Run to a Day That Already Has a Workout

Today, a day's plan is one thing — a strength workout, a rest day, or a cardio day — chosen by day_type and resolved to exactly one kind per date. There's currently no way to say "lift Push Day and go for a run" on the same day. This page inspects what that actually takes and proposes a design for it.

01What's actually missing

Checked the real code paths before proposing anything — the underlying data model turns out to already tolerate two sessions in one day; the gap is entirely in the screens.

Missing

No entry point

DayDetailScreen / TrainingDayDetailScreen offer "Start Workout" and "Choose a workout variant" for a training day — nothing that says "also log cardio today." The only way to a cardio log today is a day whose whole type is cardio.

Renders broken

Detail screens don't know cardio exists

fetchWorkoutLogDetail (shared by WorkoutLogDetailScreen and Today's CompletedWorkoutCard) selects workout_log_sets only — no cardio_log_entries. A cardio session mixed into a day would render as an empty "Workout" card with zero exercises, not a run.

Already fine

The data model doesn't need to change

A cardio log is already its own independent workout_logs row, and workoutLogIds: string[] is already plural everywhere it's threaded — WorkoutLogSection's own comment even says "more than one workout completed the same day each gets its own." Two sessions per day was anticipated; cardio just never plugged into it.

Scope if this gets approved: the entry point (screen A) is the smallest piece — "Add a Run" just navigates into the existing LogCardioScreen/ LiveCardioTrackingScreen flow with that date, nothing new to build there. The real work is extending fetchWorkoutLogDetail's query and type to also carry cardio_log_entries (duration/distance/pace/has_route), then teaching WorkoutLogSection/WorkoutLogSummarySection/CompletedWorkoutCard to render a cardio entry as a run card (screen B/D) instead of an empty exercise list — plus the small badge changes to the week-strip cell (screen C) and calendar row icon. Not started — waiting on your read of this design before any of it gets built.
