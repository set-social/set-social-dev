Notes on this mockup: map areas use a placeholder grid + drawn SVG polyline in place of real map tiles (Phase 1 recommends adding react-native-maps — see docs/gps-cardio.md). The live screen's Finish button and the summary screen's Save button are the two state transitions that matter most for review — Finish stops recording and navigates to Summary; Save calls the existing useSaveCardioLog mutation extended with route data, then navigates home exactly like today's manual-entry flow. Pause/Resume, Discard, and the permission-denied fallback state aren't pictured here but are specified in the plan doc.
